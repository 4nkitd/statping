Statping

Version 1.2.0

A website monitoring tool with a terminal dashboard, system tray, and native notifications. Connectivity-aware: when your machine is offline, monitoring pauses instead of falsely reporting sites down.

Features

  • 🌐 Internet-aware checks
  • 🔔 Confirmed-down alerts
  • 📊 Live dashboard
  • 🖥️ System tray
  • ✅ Status & keyword checks
  • 🚨 Incident history
